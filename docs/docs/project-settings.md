# Project settings

`File > Project Settings...` and the matching tool bar button open the settings of the project you
are working on. A tree on the left switches between sections; the editor of the picked section fills
the rest of the dialog. The dialog opens on the **Design** section.

## General

The **General** section is a placeholder for now. Project-wide options move here in a later version.

## Design

The **Design** section holds the shape of a page.

| Field                | Meaning                                                                 |
|----------------------|------------------------------------------------------------------------|
| Page size            | A ready-made size - A5, A4, 12.5 x 19 cm, 13.5 x 21.5 cm, 6 x 9 in - or *Custom* |
| Width, Height        | The page size in millimetres; editable only while *Custom* is chosen  |
| Inner margin         | The blank strip at the spine of the page, in millimetres              |
| Outer margin         | The blank strip at the open edge of the page, in millimetres          |
| Top, Bottom margin   | The blank strips above and below the text, in millimetres             |
| Begin with a blank page | Whether the book starts on a blank leaf                            |
| End with a blank page   | Whether the book ends on a blank leaf                              |

Values are shown in millimetres and stored in points. If the two margins of an axis leave no room
for the text between them, or a field is empty, the fields are marked and the settings cannot be
stored until the values fit.

The child sections of **Design** - the title page, the copyright page, and the typography of the
prolog, the chapters, the epilog and the blurb - are shown as placeholders for now and are filled
in a later version.

## Buttons

| Button | What it does                                        |
|--------|----------------------------------------------------|
| OK     | Stores the changes into the project and closes     |
| Apply  | Stores the changes into the project, stays open    |
| Cancel | Discards the changes and closes                    |

Closing the dialog with `Esc` or the window close button discards the changes, the same as *Cancel*.
