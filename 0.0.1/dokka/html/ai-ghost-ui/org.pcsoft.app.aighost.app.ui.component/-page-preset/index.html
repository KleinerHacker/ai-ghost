PagePreset

enum PagePreset : Enum<PagePreset>

A ready-made page size the user picks in the design project settings instead of typing width and height by hand.

The measures are kept in millimetres, the unit the dialog shows; the model is filled in points. CUSTOM carries no measures - it stands for a page the user sizes freely.
