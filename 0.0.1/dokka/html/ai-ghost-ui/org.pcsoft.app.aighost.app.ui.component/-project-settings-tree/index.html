ProjectSettingsTree

class ProjectSettingsTree : BorderPane

Navigation of the project settings dialog: a tree without a visible root, one node per ProjectSettingsSection.

The component owns no data of its own and never touches the project. It only reports which section the user picked through selectedSection, so the dialog around it decides which editor to show.
