DetailDialogViewModel

class DetailDialogViewModel : ViewModel

View model of DetailDialog.

Everything the dialog shows is an input of whoever opens it - caption, message and details carry text that is already translated, type decides the severity. The only state of its own is detailsVisible, which the user switches with the details button.
