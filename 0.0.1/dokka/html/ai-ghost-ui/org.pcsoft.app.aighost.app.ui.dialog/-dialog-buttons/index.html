DialogButtons

enum DialogButtons : Enum<DialogButtons>

Button sets a dialog of the application can be closed with.

The set is chosen independently of DialogType, so a warning can be a plain notice as well as a question. The buttons are the standard ones of JavaFX, which carry their own translation and the keyboard behaviour that belongs to them: the affirmative button answers ENTER, the negative one answers ESCAPE and the window close button.
